# GameCube button glyph provenance

These GameCube controller button/stick SVGs were created by SmashWiki user
**Toomai** and obtained from SmashWiki's **Button icons (GCN)** category.

Upstream category:
https://www.ssbwiki.com/Category:Button_icons_(GCN)

Author usage statement:
https://www.ssbwiki.com/User_talk:Toomai#Button_Icon_sources?

Toomai described these as original custom SVGs and permitted reuse. For the
SVG versions, the embedded credit comment is to remain unaltered. CarryHandle
vendors the downloaded SVG files without modifying their contents.

The original upstream filenames are preserved exactly. A SHA-256/source-URL
manifest from the vendoring run is stored alongside this note.

This note records provenance; it does not claim that SmashWiki's site-wide
content license is the license for these individual media files.
