# Zacksly GameCube controller artwork

CarryHandle intentionally vendors only the full-colour artwork used by its
GameCube controller UI:

- the 37 SVGs from `Buttons Colored/Soft Edge/SVG/`
- `Controller Images/Solid/Controller Colored SVG.svg`
- `Control Screen/Solid/Control Screen Colored.svg`

The individual button SVG files are copied byte-for-byte from the upstream
archive.  The controller and control-screen SVG contents are also unchanged;
only their destination filenames are normalized.

Upstream project:

- **GameCube Button Icons and Controls**
- **Author:** Zacksly
- **Source:** https://zacksly.itch.io
- **License:** CC BY 3.0
- **Source archive SHA-256:**
  `40b1dbe3723ffb7be80d83afb16f83bedfbee7750ea54289df055a6c1d449da7`

The upstream `LICENSE.txt` is retained verbatim beside this file.

CarryHandle build-generated raster versions are derivative/modified forms of
the SVG artwork because they are rasterized and resized for the target UI.
They remain attributed to Zacksly under CC BY 3.0.

No monochrome, hard-edge, or high-resolution PNG variants are vendored.
